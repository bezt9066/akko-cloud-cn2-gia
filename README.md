## 季付、年付、月付，同一台机器差多少钱

这部分是决定要不要一次付一年的关键，把三组账算清楚就够了。

**第一组：季付续四次 vs 直接年付。** A1 mini 季付 99 元，四个季度 99 × 4 = 396 元。年付 299 元，比按季续买省 97 元，相当于打了 75 折。配置完全一样，1 核 / 512M / 10G SSD / 500G 流量。年付唯一的代价是钱一次性付出去、中途不想用了没法退。

**第二组：月付 A1 vs 年付 A1 mini。** 这两个名字像，规格其实不同。月付 A1 是 768M 内存、600G 流量，50 元/月，一年 600 元。年付 A1 mini 是 512M 内存、500G 流量，299 元/年。多花 301 元，换来 256M 内存和 100G 流量。值不值看你跑什么：纯静态站、nginx 反代、轻量代理，512M 完全够，这 301 元可以省；要装面板、跑 MySQL、开 Docker，256M 内存带来的差别是会不会半夜被 OOM 杀掉进程，那就别省。

**第三组：年付档往上加钱买到什么。**

| 升级路径 | 差价 | 换来的东西 |

| A1 mini 299 → A2 mini 449 | +150 元/年 | 内存 512M→1G、硬盘 10G→15G、流量 500G→800G |

## 便宜档的三个真实限制

500Mbps 和 1000Mbps 是端口上限，不代表你随时能跑到这个速度。跨境线路的实际速率取决于晚高峰时段这段链路上的共享拥塞程度，商家卖的是端口能力和线路优先级，不是带宽保底。把它当成“高峰期比普通 163 线路掉得少”，比当成“随时 500M 满速”更接近实际。

不限流量档的端口从 30Mbps 起，最高 200Mbps。U1 那个 30Mbps 换算下来理论峰值约 3.75MB/s，实际还会打折。这个系列适合“怕超流量被限速”的网站和小服务，不适合拿来做下载站、视频分发、镜像源这类持续吃带宽的活。

512M 内存跑 WordPress 加面板会很紧。宝塔面板自身、MySQL、PHP-FPM 一起开，512M 经常要靠 swap 撑着，访问量一上来就顶不住。这个配置更适合静态站、Hugo/Hexo 生成的博客、纯反代、轻量代理、跑个定时脚本这类场景。要正经跑动态站，直接看 449 那档。
